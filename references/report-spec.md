# 报告结构契约

输出 `60_report.md`。五个模块，顺序固定，标题如下。不设字数目标 —— 原则是
**as simple as possible, but no simpler**：每句话必须带来新增认知，删除任何读完
没有信息增量的句子。宁可短，不要注水。

---

## 模块 1 · 60 秒摘要

**唯一判据：只读这一段，用户就该知道这个主题现在到底是什么情况。**

- 3–6 句话，或 ≤ 150 字。
- 必须包含：这个主题当前的状态、最反直觉的一点、对用户而言最相关的一个后果。
- **禁止**出现「本文将…」「综上所述」「在各个领域中」这类空转句。
- **禁止**在此处放引用标记 —— 细节留给后面的发现。

## 模块 2 · 五个最重要的发现

按**可靠性从高到低**排序，不是按重要性拍脑袋排。

排序键（依次比较）：
1. 可信度等级 A > B > C > D
2. 多视角共识（支持的视角越多越靠前）
3. 来源时间新近性

每条发现的固定格式：

```
### F1. <一句话结论，本身就要能独立成立>

- **可靠性**：A — <为什么是 A：来源类型/可复核性>
- **支持视角**：从业者、经济学家
- **反对或保留**：怀疑者 — <最强反对意见原文级复述>
  （若确实无人反对，写「未找到实质性反对」，不要编一个）
- **证据**：<断言> [S3][S7]
- **边界**：<在什么条件下这条不成立 / 结论外推到哪里就失效>
```

规则：
- **证据不足时只写 3 条或 4 条**，并在模块开头说明：本主题公开证据薄弱。
  凑满 5 条是错误。
- 反对视角一栏**不许空**。Skeptic 是必填项来源，其他视角的异议也要记。
- 每条发现的「边界」必须写。没有边界的结论基本都是过度概括。

## 模块 3 · 隐藏联系

找出不同视角的观点之间**最不容易发现的关联**。这不是总结，是综合。

- 2–4 条。少于 2 条说明综合做得不够，多于 4 条说明在凑数。
- 每条必须回答三件事：

```
### H1. <这个联系是什么>
- **连接的是什么**：<视角 X 的哪条事实> ↔ <视角 Y 的哪条事实>
- **为什么不易发现**：<两个视角各自都看不到对方的材料 / 时间尺度不同 / ...>
- **置信度**：高/中/低 — <判断依据>
```

- **红线**：两个事实之间若没有被任何来源**明确**连接，必须标为「推测」并说明
  推测链条。原论文最大的实证缺陷就是模型把来源里没说关系的东西硬连起来
  （red herring），这一栏是重灾区。
- 来源**明确**说过的关系，不需要放这一栏 —— 那是普通发现。

## 模块 4 · 可执行建议

**只针对 `references/user-profile.md` 里的那个人写。** 不是给「读者」写的通用建议。

- 3–5 条。每条固定四要素：

```
### A1. <动作，动宾短语开头，不要「可以考虑...」>
- **对应发现**：F2
- **做什么**：具体到能直接开工（工具名 / 论文编号 / 数据集 / 具体实验设计 / 具体学习路径）
- **为什么是他能做**：<调用画像里的已有能力，说明不需要从零补什么>
- **缺口**：<要补的最小前置知识是什么，补到什么程度就够>
```

规则：
- 必须落在画像的能力范围内，或明确标出「需要先补 X」且 X 是**最小**缺口。
- 建议要能反驳：如果一条建议换个领域的博士也能照做，说明不够针对性，重写。
- 严格执行画像里的表达约束（见下）。

## 模块 5 · 前沿问题

**判据：如果这个问题被解决，该主题领域将被重新定义。**

- 1–3 个。不是「未来研究方向」清单 —— 那些只是增量。
- 每个问题写：问题本身 + 为什么它被解决就等于重定义 + 目前卡在哪
  （缺数据？缺理论？缺算力？还是问题本身定义不清）。

## 全文表达约束（来自用户画像，强制执行）

1. **不要无谓的物理比喻**。任何类比都必须先确认它属于哪个领域，再用该领域的语言。
2. **按领域切语言**：物理部分用物理语言，计算机科学部分用 CS 语言，AI 部分用
   AI 领域术语。不混用，不用甲领域的行话去解释乙领域。
3. **参考文本相关的内容，沿用参考文本自身的语言风格和用词**，不要换成自己的腔调。
4. **不许绕过数学**。推理过程需要数学推导/展示时，保留完整的推导过程；
   实在放不下，至少给出所用数学工具的名称，让用户能自行复现验证。
5. 引用统一用 `[S<编号>]`，编号与 `30_sources.md` 一致；报告末尾附来源清单，
   每条含：标题、URL、可信度等级、访问日期。
